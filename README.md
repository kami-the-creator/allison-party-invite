# Invitación estilo Rapunzel — GitHub Pages

Proyecto estático listo para publicar. No requiere instalar Node.js ni ejecutar comandos.

## Publicación rápida

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `styles.css` y `script.js` a la raíz del repositorio.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama **main**, carpeta **/(root)** y pulsa **Save**.

## Personalización

Edita `index.html` para cambiar nombres, direcciones, horarios, textos y enlaces. En `script.js` puedes cambiar la fecha de la cuenta regresiva, la cuenta bancaria y el texto de WhatsApp.
